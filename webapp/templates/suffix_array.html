Suffixarray

Das Suffix Array ist eine sortierte Liste aller Suffixe eines Texts. Durch eine binäre Suche in diesem Array können die Positionen der Muster im Text gefunden werden. Es benötigt weniger Speicherplatz im Vergleich zu anderen Strukturen wie dem Suffix-Trie und -Baum und eignet sich gut für Anwendungen mit begrenztem Speicher.

Bitte beachte: Die folgende Methode führt eine binäre Suche durch und gibt eine Vorhersage darüber ab, ob das Muster im Text vorhanden ist. Die Positionen, an denen das Muster im Text auftritt, werden hierbei jedoch nicht ermittelt.
